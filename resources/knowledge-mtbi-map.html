Four machine-group signatures

from the top-5 CA + MCA tables

The same top-5 rows keep naming the same handful of machine groups. Grouping by why each one shows up separates four different problems that each need a different response — not one blanket "reduce interruptions" initiative.

A

Volume drivers — the short-stop cluster

MCA top-5 by interruption time

These groups dominate total interruption time, almost entirely under one recurring reason code: "DC=Short stop". High frequency, short duration — a classic micro-stop signature, not a reliability crisis.

  • WB-ASM 283h total · 82% Critical-level · #1 combo: DC=Short stop + Critical, 230 events, 83h33m (4.4% of all interruption time)
  • WB-KS 371h total · 79% Critical-level · #2 combo: DC=Short stop + Critical, 332 events, 48h59m (2.6%); also PDT Error-BITS Error NSOL + Critical, 35h46m (1.9%)
  • DS-DISCO 187h total · 77% Critical-level · 3rd-largest group overall; shares the short-stop signature with the wire-bond pair
  • DA-ESEC 174h total · 80% Critical-level · DC=Short stop + Critical, 187 events, 36h22m (1.9%)
  • DA-ASM 111h total · 74% Critical-level · DC=Short stop + Critical, 228 events, 28h45m (1.5%)

B

Critical-skew groups — predictive-maintenance candidates

CA top-5 std. residuals, Group × Level

Almost none of these groups' interruptions are minor — nearly every logged event is Critical or High. That pattern points to occasional severe failures, not routine micro-stops, making them the best candidates for predictive maintenance.

  • HDLR-MULTITEST std. resid. +46.80 (largest in the study) · 1,040 Critical events vs. 270 expected · 99.5% Critical overall
  • HDLR-ISMECA std. resid. +42.65 · 828 High-level events vs. 210 expected
  • CLNR-MARCH std. resid. +39.94 · 814 Critical events vs. 221 expected · 99.3% Critical overall
  • HDLR-TESEC std. resid. +35.47 · 605 Critical events vs. 159 expected
  • HDLR-MCT std. resid. +32.50 · 528 Critical events vs. 142 expected · 99.4% Critical overall
recommended fixPredictive / condition-based maintenanceFailure-mode review per group
C

Exclusive fault fingerprints — single-machine idiosyncrasies

CA + MCA top-5, Group × Reason Code & by lift

Every closest-pairs table in the study agrees: these reason codes belong to exactly one machine group (map distance ≈ 0.000, lift up to ~10,000x chance). They are equipment idiosyncrasies to fix at the machine, not a shared process cause.

  • INSP-CAMTEK reason code "514" is 100% exclusive to this group · std. resid. +220.9, the strongest cell in the entire study
  • MOLD-FICO "MOLD STATION" exclusive (std. resid. +165.3) · also the #1 lift combination in the core model at 9,945.63x chance
  • WB-ORTHODYNE both "OUTPUT ELEVATOR" and "CHANGE CAPILLARY" exclusive (std. resid. +156.2 each)
  • INSP-MUHLBAUER "ENROULEUR/DEROUL" exclusive, std. resid. +146.1, 32 events
  • POTT-MUHLBAUER "RAYURES" and "CHGT RESINE" both in the core model's top-5 lift table, 3,700–5,600x chance

Product-coupled groups — process window, not the machine

CA top-5 std. residuals, Group × Product Code

These machine groups are effectively dedicated to a single product family. Interruptions attributed to "the machine" here may really trace back to that product's process window — worth separating in future root-cause reviews.

  • DFLH-ALLMERIT std. resid. +199.8 with MB1P*GWFIB5K/8K · exclusive despite only 9 events
